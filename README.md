# Bhushan Karande — Hugo Site

This repository contains a Hugo site using the PaperMod theme.

## Structure

- `archetypes/`: Content templates.
- `assets/css/extended/`: Custom styles (`about.css`, `post-toc-left.css`).
- `content/`: Site content including `about/`, `notes/`, and `blog/` (leaf bundles).
- `static/`: Static assets such as `img/profile.jpg` and the resume PDF.
- `themes/PaperMod/`: Theme.
- `hugo.yaml`: Site configuration.

## Local Development

```bash
hugo server -D
```

Open http://localhost:1313 to preview drafts.
